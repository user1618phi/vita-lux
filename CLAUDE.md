# Vita Lux — интернет-магазин сантехники

## Команды
- Разработка: `pnpm dev` (сторфронт :8000, Medusa :9000)
- Типы: `pnpm typecheck` — ОБЯЗАТЕЛЬНО после серии правок
- Линт: `pnpm lint`
- Тесты: `pnpm test` — запускай точечно, не весь набор
- Миграции: `npx medusa db:migrate` — только через CLI, не через MCP

## Стек
Next.js 15 App Router, TypeScript strict, Tailwind CSS v4 (`@theme`),
Medusa v2, PostgreSQL, Meilisearch.
Server Components по умолчанию. Клиентские — только там, где нужна
интерактивность.
Запрещены UI-библиотеки со своим визуальным стилем (MUI, Ant, Chakra,
Bootstrap). Radix UI Primitives разрешён — только за поведение, без стилей.

## Бренд — КРИТИЧНО
Vita Lux — производитель, сайт моно-брендовый.
НИКОГДА не упоминай Grohe, Hansgrohe, Roca, Cersanit и другие чужие бренды —
ни в коде, ни в текстах, ни в тестовых данных. Дилерских договоров нет.
В моковых данных бренд только `Vita Lux`.
Поля `brand` и `rating` в модели товара НЕТ.

## Mobile-first
Более 75% трафика мобильный. Проверяй на 390px первым, потом расширяй.
Размер шрифта в полях ввода строго 16px — иначе iOS зумит страницу.

## Двуязычность ru/kk — КРИТИЧНО
Ключи i18n в `/messages`. НИКОГДА не хардкодь текст в JSX.
YOU MUST проверять казахские глифы ә ө ұ ү қ ң ғ һ і после правки kk-локали.
Казахский текст на 10–20% длиннее русского — проверяй, что верстка не ломается.

## Токены
Компоненты используют ТОЛЬКО семантические токены
(text-primary, surface-page, border-control и т.д.),
никогда не примитивы напрямую.
Единственный источник правды по значениям токенов — `@theme` в
`src/styles/globals.css`. Не дублируй хексы в компонентах.
brass #a97c50 нельзя использовать как цвет текста — не проходит контраст.
Для текста: `--brass-text` #83602f на светлом, `--brass-text-dark` #c8a077 на тёмном.

## Платежи — КРИТИЧНО, не ломать
Halyk ePay + Kaspi Pay/Kaspi Red. Все суммы в тенге, целые числа.
Секреты только в env. НИКОГДА не логируй платёжные payload.
WhatsApp click-to-chat: генерируй реф-код на сервере и пиши в БД —
на этом держится учёт продаж по каналу.
